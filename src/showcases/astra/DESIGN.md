# Pelican Rider
A code-built kinetic sculpture: an ivory pelican riding a vermilion touring bicycle through a miniature seaside diorama. Real geometry, procedural materials, articulated feet, animated spokes and scarf. This is an iterative creative coding showcase, inspired by the pelican SVG prompt; it is not that original one-shot SVG benchmark.

Visual direction: warm porcelain / sophisticated toy photography. Light oat page #f4f0e6, dark ink #263d39, coral #dc613e, seafoam #b7d9cf, sunset apricot. No photographic or generated image assets. Official unchanged TKT icon/logoname only. System serif title, system sans controls. Generous open composition, large central 3D scene; minimal typography at top, light controls at bottom. Mood changes to deep navy and luminous mint at night.

UI copy: Pelican Rider; A little bird. A very long ride.; Built with GPT-6 Astra · xhigh; Coast / Studio; Day / Sunset / Night; Cruise / Sprint; Orbit; Pause / Ride; Drag to explore. Scroll to zoom.; Source. Responsive scene fills available view.

Video: begin with the complete beautiful scene already moving. Show sprint, sunset to night, orbit, studio view, then a clean return to the coast. Approx 25 seconds. Real browser interaction, no fabricated model output, no speed-up. Silent, readable when autoplay-muted.
