操作说明

  • W/↑ 加速
  • S/↓ 刹车（滑行有棘轮声）
  • A/D 左右变道抓鱼
  • 空格 跳跃
  • T 放手展翅 + 抬前轮
  • B 按车铃
  • H 鹈鹕大叫
  • C 切换镜头
  • Q/E 手动换挡
  • N 时间快进 3 小时
  • M 声音开关
  • Esc 返回工作台
  • U 隐藏界面
  • P 暂停

拖拽旋转视角、滚轮缩放。点击鹈鹕它会叫，点击车铃会响，点击远处海面会有鱼跃出。几秒不操作会自动驾驶去追鱼；金色的鱼值 5 分。背景音乐是实时合成的，节奏跟随踏频。
