# 浏览器连接本机工作台

网页直接使用桌面端的界面、Codex 制作后台、素材工具、审查与自动试玩。Codex 使用本机已有的 ChatGPT 登录，账号凭据保留在电脑上。

## 打开

在项目目录运行：

```sh
npm run desktop:web
```

使用时保持这个后台运行，电脑保持开机、联网且不休眠。闲置时可在运行命令的终端按 `Ctrl+C` 退出后台并关闭网页，避免持续的云端状态查询。配置远程网站后，命令会自动打开现有域名；首次打开通过连接密钥配对，后续使用浏览器会话。重复执行命令会打开正在运行的工作台。密钥用于连接能操作你本机项目的私人工作台。

### 在另一台电脑打开

先在运行 Codex 的这台 Mac 上保持 `npm run desktop:web` 运行，再在项目目录执行：

```sh
npm run desktop:web:pair
```

命令会把私人连接链接复制到这台 Mac 的剪贴板。通过仅你自己可访问的方式把链接传到另一台电脑，在那里粘贴到浏览器打开。网页会自动完成配对，然后显示这台 Mac 上的 Codex 账号状态、项目和制作流程。下次同一浏览器打开 `https://ludoready.bleakbelladonna.com/` 时可使用已有会话；会话过期后重新配对即可。不要把私人连接链接发给其他人。

本机页面为 `http://127.0.0.1:8790/`。受保护的连接地址保存在本机 LudoReady 用户目录的 `desktop-web/connection.json` 中；不要公开该文件或带连接密钥的完整链接。

## 使用

1. 在桌面端同一首页输入一句游戏创意。
2. 网页显示实际 Codex 制作记录和必要的审批；允许后继续执行。
3. 在预览中试玩，查看素材与项目文件，下载可独立运行的网页游戏。
4. 在原项目里输入修改要求，继续同一制作流程。

已实际验收小型 2D Web 游戏的生成、12 步试玩、审批、继续修改及下载。附件每次合计最多 20MB，单个网页预览资源最多 20MB，下载包最多 40MB；Godot 大型导出尚未进行网页端验收。

网页创建的工程自动保存在桌面设置的项目目录中。浏览器附件会先传到本机再进入项目。选择本机目录、引擎文件和打开文件夹的操作由本机执行。生成游戏在隔离的页面中运行，不能调用工作台控制接口。

## 运行与部署

`.env.desktop.local` 保存本机连接配置，并被 Git 忽略；请勿上传它。

- `LUDOREADY_DESKTOP_ORIGIN`：现有 HTTPS 网站地址。
- `LUDOREADY_DESKTOP_PREVIEW_ORIGIN`：已绑定的独立试玩域名，使游戏保留浏览器存储能力，同时与工作台隔离。
- `LUDO_DESKTOP_SECRET`：与云端一致的工作台连接密钥，自动生成。
- `LUDOREADY_CODEX_BIN`：可选，指定 Codex 可执行文件；默认采用已安装的 CLI。
- `LUDOREADY_DESKTOP_PORT`：可选，本机默认端口 8790。

构建桌面网页发布包：

```sh
npm run desktop:web:build:edgeone
```

输出是 `dist/desktop-edgeone`。云端使用现有 EdgeOne 项目、CloudBase 状态服务及 `src/web/desktopRelay/state.sql`，无需启动云服务器。原有 `/play/` 游戏地址继续保留。

电脑离线时，网页会显示离线状态，新的本机制作和预览暂不可用。重启后台后仍能打开已保存在本机的项目。Codex 使用订阅额度；腾讯云的函数、状态服务与数据库仍按各自套餐和用量计算，另行配置的图片、音频 API 也按其服务计费。旧版广州 SCF 的每分钟定时任务已于 2026-09-28 停用。
