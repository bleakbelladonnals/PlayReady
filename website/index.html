GOOD QUESTIONS

开始之前，
你可能想知道。

我需要会写代码吗？+

你可以用自然语言描述玩法和修改要求，PlayReady 会生成素材与代码。清晰描述规则、亲自试玩并反馈，会让结果更接近你的想法；有开发经验也能直接查看和调整工程。

使用之前需要准备什么？+

一台 Mac、可用的 ChatGPT/Codex 账户，以及可用的图片生成方式。图片可以通过配置的图片服务或 Codex ImageGen 生成；需要使用 Godot 时，还需要相应的 Godot 4 和 Web 导出模板。

可以做哪些类型的游戏？+

支持 Web 游戏与 Godot 4 工程。建议先从规则清晰的小型玩法开始，例如躲避、跑酷、收集或解谜，再逐步增加内容。当前 Godot 自动交付采用 Web 导出。

会使用我的模型额度吗？+

会。制作游戏会使用你登录的 Codex 账户；额外配置的图片、音频或 3D 服务，按对应服务的额度和计费方式使用。具体用量取决于游戏内容与修改次数。

作品保存在什么地方？可以继续修改吗？+

桌面工作台的工程保存在你选择的本地项目目录里。可以回到原项目提出修改，也可以查看、复制或使用其他工具继续编辑工程。AI 制作过程需要联网。

网页试玩和网页工作台有什么区别？+

这里的作品可直接在浏览器里玩。网页工作台用于连接电脑上的 PlayReady 制作后台，使用时需要保持电脑开机、联网并运行后台。
